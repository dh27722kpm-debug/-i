# 生活记录台 🐱

单文件 PWA，记录日常 + 模拟冰箱贴纸。

## 🚀 放到手机桌面（最快）

解压后双击 **`启动服务.bat`**（Windows）或 **`启动服务.command`**（macOS），
终端会显示**二维码**和网址；手机连同一 WiFi 扫码 → 按引导页提示"添加到主屏幕"。

> 想要永久网址（电脑关机也能用）：把整个文件夹拖到 **https://app.netlify.com/drop**，
> 立刻得到 `https://xxx.netlify.app` 网址，手机打开该网址再添加到主屏幕。
> 详见 **部署指南.md**。

也可以直接双击 `index.html` 在电脑浏览器里用。

## 功能
- **记录页**：洗澡 / 洗头点一下即记；喝奶茶、外出吃饭、运动、逛超市带常规选项快捷填表
  - 每类都有「时段」选项（早餐 / 午餐 / 下午茶 / 晚餐 / 睡前…），选时段即决定记录落在几点
  - 超市的「购买物品」与外食的「菜品」支持多选，自动用「、」连接
- **日历页**：每个类别一个颜色，格子下方彩色圆点一眼看出哪天做了什么
- **冰箱页**：粉色可爱冰箱，点击开门；上冷冻下冷藏，物品以手绘贴纸呈现
  - 放入食物时提供：常见食物名（点一下自动带出分类）、分类（决定贴纸图案）、冷藏/冷冻、保质期快捷时长
  - 记录放入时间与过期时间；未填过期日期时按内置保质期规则自动建议
  - 点贴纸可查看详情、修改过期时间、吃掉或扔掉

## 🐱 图标显示不对？

桌面上显示旧图标时：先**长按旧图标删除**，再重新添加；或打开应用点「🐱 修复桌面图标」。
详见 **部署指南.md** 的图标排查章节。

## 文件
| 文件 | 说明 |
| --- | --- |
| `index.html` | 应用主程序（单文件，含全部逻辑与样式） |
| `install.html` | 手机端安装引导页（含二维码与图文步骤） |
| `start-server.py` | 一键启动局域网服务器 + 生成二维码 |
| `启动服务.bat` / `启动服务.command` | Windows / macOS 双击启动 |
| `manifest.webmanifest` | PWA 配置 |
| `sw.js` | Service Worker（图标不走缓存） |
| `icon-192.png` / `icon-512.png` | 桌面图标 |
| `icon-maskable-512.png` | 安卓自适应图标（防裁切） |
| `apple-touch-icon.png` | iOS 桌面图标 |
| `life-log-icon.svg` | 图标矢量源文件 |
| `部署指南.md` | 完整部署与排错指南 |

## 数据
- 存储位置：浏览器 localStorage（键名 `lifeLog.v2`），不上传任何服务器
- 旧版 `lifeLog.v1` 数据会自动迁移
- 首页可导出 / 导入 JSON 备份（含冰箱物品）
