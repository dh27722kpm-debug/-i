# 📱 放到手机桌面 · 完整指南

三种方式，按推荐顺序选一个就行。

---

## 方式一：局域网直连（最快，1 分钟，不用账号）

### 步骤

1. 解压 `life-log-deploy.zip` 到任意文件夹
2. 在该文件夹里运行：

   | 系统 | 操作 |
   | --- | --- |
   | **Windows** | 双击 `启动服务.bat` |
   | **macOS** | 双击 `启动服务.command`（首次可能需右键 → 打开） |
   | **任意** | 终端执行 `python3 start-server.py` |

3. 终端会打印出**二维码**和网址，例如 `http://192.168.1.8:8848/index.html`
4. **手机和电脑连同一个 WiFi**
5. 手机**扫码**（或手动输入那个网址）→ 自动打开 `install.html` 安装引导页
6. 点「直接打开应用」→ 按页面上的提示添加到主屏幕

> ⚠️ 电脑关机 / 退出程序后，手机上的图标点开会提示"无法连接"。想长期用请看方式二。

## 方式二：免费托管（推荐，一次搞定长期使用）

把文件夹传到免费静态托管，生成一个永久网址，手机随时能装。

### 方案 A：Netlify Drop（最简单，不用注册）

1. 电脑浏览器打开 **https://app.netlify.com/drop**
2. 把解压出来的**整个文件夹**直接**拖到网页上**
3. 等几秒，会得到一个类似 `https://xxxx-xxxx.netlify.app` 的网址
4. 手机打开这个网址 → 「添加到主屏幕」
5. 之后即使电脑关机也能用 ✅

> 想要自己的域名：Netlify 后台 → Site settings → Change site name

### 方案 B：Vercel

1. 打开 **https://vercel.com/new**
2. 选择 **Other** → 拖拽文件夹上传（选 `Other` 里的 "Upload a Directory"）
3. 部署完成，得到 `https://xxx.vercel.app`
4. 手机打开 → 添加到主屏幕

### 方案 C：GitHub Pages（免费且永久，适合会折腾的）

```bash
# 1. 新建仓库，把解压出来的文件 push 上去
cd life-log-deploy
git init && git add . && git commit -m "life log"
git branch -M main
git remote add origin https://github.com/你的用户名/life-log.git
git push -u origin main

# 2. 仓库设置 → Pages → Source 选 main 分支 / root → 保存
# 3. 1~2 分钟后得到 https://你的用户名.github.io/life-log/
```

### 方案 D：Cloudflare Pages / 阿里云 OSS / 腾讯云 COS

都是上传静态文件、绑定域名即可，同样可用。若已有服务器，直接把文件夹丢进网站目录也行。

## 各平台添加到主屏幕的具体操作

### iPhone（必须用 Safari）

1. Safari 打开网址
2. 底部中间的 **「分享」按钮**（方框里一个向上箭头 ↑）
3. 菜单向下滑，找到 **「添加到主屏幕」**
4. 可改名为「生活记录」，右上角点 **「添加」**

### 安卓

| 浏览器 | 操作 |
| --- | --- |
| Chrome | 右上角「⋮」→「添加到主屏幕」/「安装应用」 |
| Edge | 底部菜单「⋮」→「应用」→「安装此站点为应用」 |
| 三星浏览器 | 底部「⋮」→「添加到主屏幕」 |
| 小米/华为自带浏览器 | 菜单 →「添加到桌面」 |

### 电脑（Chrome / Edge）

地址栏右侧会出现「安装」图标（⊕ 或显示器形状），点一下即可装成独立窗口应用。

## 图标显示不更新？🐱

桌面上还是旧图标（图标本身就是旧的、或变成了默认图标）：

1. **先长按旧图标删除** — 这步最关键，系统会复用已缓存的图标
2. 重新用新网址添加一次
3. 还不对 → 打开应用首页点 **「🐱 修复桌面图标」**（会强制刷新图标缓存并清空 SW）
4. 实在不行 → 点 **「🧹 清空缓存重置」**，然后浏览器强制刷新（Ctrl/Cmd + Shift + R）再添加

## 常见问题

**Q：图标是一块白底/黑色方块？**
A：iOS 要求 apple-touch-icon 不能有透明通道。本包已用不透明 RGB 生成，正常不会出现。若你自行替换过图标，记得存成 RGB（无 alpha）PNG。

**Q：添加到主屏幕后打开是网页而不是全屏？**
A：检查 manifest 是否被加载。把 `manifest.webmanifest` 和 `index.html` 放在同一目录，网址以 `index.html` 结尾访问。

**Q：数据会丢吗？**
A：数据存在手机浏览器的 localStorage 里，**跟服务器无关**。但清理浏览器数据 / 卸载会清空。建议定期在应用首页「导出数据 (JSON)」备份。

**Q：换手机/换浏览器数据会丢吗？**
A：会。导出一份 JSON，在新设备上「导入数据」即可，冰箱物品也一起迁移。

**Q：手机上打不开局域网地址？**
A：检查 ① 手机电脑是否同一 WiFi ② 电脑防火墙是否拦截（Windows 首次运行会弹窗，选「允许」）③ 试试 `python3 start-server.py --port 8080` 换端口。

**Q：能多人共用一份数据吗？**
A：当前是纯本地存储，各自独立。要共享可以自己接个后端 API，数据层已集中在 `DB` 对象里，改造不难。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `start-server.py` | 一键启动局域网服务器 + 生成二维码 |
| `启动服务.bat` | Windows 双击启动 |
| `启动服务.command` | macOS 双击启动 |
| `install.html` | 手机端安装引导页（含二维码与图文步骤） |
| `index.html` | 应用主程序 |
| `manifest.webmanifest` | PWA 配置（应用名、图标、启动方式） |
| `sw.js` | Service Worker（保证图标不被旧缓存污染） |
| `icon-192.png` / `icon-512.png` | 桌面图标 |
| `icon-maskable-512.png` | 安卓自适应图标（防裁切） |
| `apple-touch-icon.png` | iOS 桌面图标 |
| `life-log-icon.svg` | 图标矢量源文件 |
