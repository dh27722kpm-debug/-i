直接打开应用 →

📱 iPhone（Safari）

  1. 用 Safari 打开上面的网址（必须是 Safari，微信/QQ 浏览器不支持）
  2. 点底部中间的「分享」按钮 ↑
  3. 在菜单里向下滑，找到 「添加到主屏幕」
  4. 右上角点 「添加」，桌面就会出现猫咪图标 🐱

🤖 安卓（Chrome / Edge / 三星浏览器）

  1. 用浏览器打开上面的网址
  2. 点右上角 「⋮」 菜单
  3. 选 「添加到主屏幕」 或 「安装应用」
  4. 确认后桌面出现猫咪图标 🐱
💡 图标显示不对？
桌面上显示的是旧图标的话，先长按旧图标删除，再重新添加一次；
或者打开应用点首页的「🐱 修复桌面图标」按钮，一键刷新图标缓存。
⚠️ 关于本页面地址
本页由电脑上的 start-server.py 生成，电脑关机后地址就失效了。
想长期使用，请看 zip 里的 部署指南.md，有免费托管的详细步骤。
数据保存在手机浏览器本地，不上传任何服务器
首次打开后建议在应用里「导出数据」做一份备份
